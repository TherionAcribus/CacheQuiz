# Internationalisation (i18n) — CacheQuiz / QuizGeocaching

Ce projet utilise **Flask-Babel** + **Babel/pybabel** pour traduire l’interface (templates Jinja, messages backend, etc.).

## Commandes utiles

### Script PowerShell (recommandé sous Windows)

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\i18n.ps1
```

### 1) Extraire les chaînes

```bash
pybabel extract -F babel.cfg -o messages.pot .
```

### 2) Initialiser une langue (ex: anglais)

```bash
pybabel init -i messages.pot -d translations -l en
```

### 3) Mettre à jour les catalogues après modifications

```bash
pybabel update -i messages.pot -d translations
```

### 4) Compiler (génère les `.mo` utilisés à l’exécution)

```bash
pybabel compile -d translations
```

## Sélection de langue dans l’app

- **Querystring**: `?lang=en` (prioritaire, ne persiste pas)
- **Cookie**: via `GET /set-language?lang=en&next=/...` (persiste 1 an)
- **Fallback**: en-tête `Accept-Language`, puis `fr`
